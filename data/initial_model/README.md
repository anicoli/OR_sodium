# Initial Structural Models

## Overview
This folder contains the initial structural models (PDB files) of the investigated odorant receptors used as starting structures for MD simulations.

## File Format
The PDB files contain:
- Atomic coordinates for the receptor structure
- Additional hydrogens

## Notes
These structures are prepared using the Protein Preparation Wizard tool (Schrödinger Release 2024-3, Maestro, Schrödinger, LLC, New York, NY, 2024).
